# Grok Build format references

Checked 2026-11-12.

- [Skills, Plugins & Marketplaces](https://docs.x.ai/build/features/skills-plugins-marketplaces) documents user-level skills, plugin component folders, plugin installation, plugin validation, and enabling plugins.
- [Modes and Commands](https://docs.x.ai/build/modes-and-commands) documents user-invocable skills as slash commands and supports invoking skills by name.
- [CLI Reference](https://docs.x.ai/build/cli/reference) lists `grok plugin validate`, `grok plugin install`, `grok plugin enable`, `grok plugin list`, and `grok inspect`.
- [Settings Reference](https://docs.x.ai/build/settings/reference) documents `GROK_HOME`, the Grok home directory, persistent skill/plugin paths, and host-controlled configuration.
- [Permissions](https://docs.x.ai/build/features/permissions) explains tool permission modes and allow/deny behavior; the package manifest cannot itself grant tools or bypass permission rules.
- [Sandbox](https://docs.x.ai/build/features/sandbox) describes filesystem and network constraints imposed by the active Grok Build environment.

The operator requested Vercel deployment but excluded Vercel connection material. The package therefore references only an already-authenticated Vercel CLI and does not configure a connector or OAuth connection.

Grok Auto-Build Engine

Installable /build skill with checkpointed continuation. Operator can authorize a 50-run budget while phase and checklist stay intact. Production host: https://auto-build-engine.vercel.app.

Install on a machine with Grok Build CLI

  1. Download the ZIP or clone this repository.
  2. Enter the package root and run ./install.sh.
  3. Use /build or /build continue.

Download ZIP install.sh plugin.json SKILL.md

Checkpoint budget

  • Default budget: 5 runs per objective.
  • Operator may authorize another 50 runs; phase and checklist are kept; runs_used resets to 0.
  • Install checks do not spend a run. Finish-with-limitation does not spend a run.
  • A production URL is claimed only after a verified live deployment.
